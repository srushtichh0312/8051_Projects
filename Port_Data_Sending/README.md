# 8051 Port Data Sending

## Project Overview

This project demonstrates port data handling using the 8051 microcontroller. The hardware circuit is designed using Proteus Design Suite to understand how data can be sent through the microcontroller's I/O ports.

## Tools Used

- **Microcontroller:** 8051
- **Simulation Software:** Proteus Design Suite
- **Project File:** `Push_8051.pdsprj`

## Project Files

| File Name | Description |
|---|---|
| `Push_8051.pdsprj` | Main Proteus project file |
| `Push_8051.pdsprj.ASUS.metst.workspace` | Proteus workspace file |

## How to Open the Project

1. Install Proteus Design Suite.
2. Download or clone this repository.
3. Open the `Push_8051.pdsprj` file in Proteus.
4. View the circuit design and run the simulation if the required design files are available.

## Learning Objectives

- Understand 8051 microcontroller I/O ports.
- Explore port data handling.
- Gain practical experience with Proteus-based hardware design.
