# 8051 Microcontroller Projects

A collection of beginner-friendly projects and practical experiments based on the **8051 Microcontroller**. This repository is created to explore embedded systems fundamentals, understand microcontroller programming, and gain hands-on experience with hardware interfacing.

## 🎯 Objectives

- Understand the architecture and working of the 8051 microcontroller.
- Learn Embedded C programming and basic microcontroller concepts.
- Practice interfacing different electronic components and peripherals.
- Develop practical skills through circuit design and simulation.
- Build a foundation for learning advanced embedded systems.

## 🛠️ Tools & Technologies

| Category | Technology |
|---|---|
| Microcontroller | 8051 |
| Programming Language | Embedded C |
| IDE | Keil µVision |
| Simulation Software | Proteus Design Suite |
| Development Area | Embedded Systems & Hardware Interfacing |

## 📂 Projects Included

This repository contains 8051-based programming examples and hardware interfacing projects.

Each project is organized in its respective folder. Refer to the individual project files for source code, circuit diagrams, and simulation details wherever available.

## ⚙️ How to Run the Projects

1. Clone or download this repository.
2. Install Keil µVision and Proteus Design Suite.
3. Open the required project in Keil µVision.
4. Compile the Embedded C program and generate the HEX file.
5. Open the corresponding circuit in Proteus.
6. Load the generated HEX file into the 8051 microcontroller.
7. Run the simulation and observe the output.
